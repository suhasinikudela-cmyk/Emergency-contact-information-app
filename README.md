# Emergency-contact-information-app
Work on the frontend developer
Emergency Contact Information Management System
## 2. Abstract
The Emergency Contact Information App is a user-friendly application designed to store and manage important emergency contact details.
This application allows users to save emergency contacts such as family members, friends, doctors, and other important people. Users can easily view and access these contact details whenever required.
The main objective of this project is to provide quick access to emergency contact information and improve communication during emergency situations.
## 3. Objectives
Store emergency contact information.
Add, update, and delete contacts.
Display emergency contact details.
Provide quick access to important phone numbers.
Create a simple and user-friendly interface.
## 4. Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Python
Database: SQLite
Framework: Flask
Version Control: Git and GitHub

## 5.Project Modules

## 9.Conclusion
The Emergency Contact Information App is a useful and user-friendly application developed to store and manage important emergency contact details. It helps users quickly access phone numbers of family members, friends, and other important people during emergency situations.
This project reduces the time required to find emergency contacts and provides an easy way to add, update, view, and delete contact information. It can be further enhanced with SOS alerts, GPS location sharing, and emergency notifications.
